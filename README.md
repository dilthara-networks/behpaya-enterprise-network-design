# Enterprise Network Design – Behpaya Information Technology

## Project Overview

This is a group academic project completed for the Data Communication and Wireless Networks (IE2100) module at the Sri Lanka Institute of Information Technology (SLIIT).

The project focuses on proposing a secure, scalable, and reliable enterprise network infrastructure for a two-floor office environment supporting approximately 50 employees.

## Project Objectives

- Design a proposed enterprise LAN and WLAN infrastructure.
- Develop a hierarchical star network topology.
- Plan VLAN segmentation and IPv4 addressing.
- Design wireless access point deployment.
- Propose network security and firewall solutions.
- Plan network services and network management.

## Network Technologies and Concepts

- Cisco Packet Tracer
- Enterprise LAN and WLAN Design
- Cisco Routers and Switches
- VLAN Segmentation
- IPv4 Addressing and Subnetting
- Wi-Fi 6 Network Design
- Network Security and Firewall Concepts
- DHCP and DNS
- SNMP Network Monitoring

## Network Design

The proposed architecture uses a Hierarchical Star Topology to connect the two office floors.

### VLAN Design

| VLAN ID | Purpose |
|---|---|
| VLAN 10 | Staff |
| VLAN 20 | Admin |
| VLAN 30 | Guest |
| VLAN 40 | Servers |
| VLAN 50 | Management |

### IP Addressing Scheme

| VLAN | Network |
|---|---|
| VLAN 10 | 192.168.10.0/24 |
| VLAN 20 | 192.168.20.0/24 |
| VLAN 30 | 192.168.30.0/24 |
| VLAN 40 | 192.168.40.0/24 |
| VLAN 50 | 192.168.50.0/24 |
